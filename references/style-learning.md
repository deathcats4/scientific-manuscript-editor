# Learning transferable writing features

Use this reference only when the user asks to learn a supplied paper's writing
style, reasoning presentation, paragraph organization, or comparable
features. It supports [reference-use.md](reference-use.md); it does not replace
the author's evidence, scientific position, or voice.

## Start with the target

Before analysing the source, identify the author's target section, reader,
current claim, evidence, inference chain, and requested kind of improvement.
Style learning is useful only when a feature solves that target's problem. Do
not build a full style profile for a source used only for citation, background,
or factual verification.

## Extract tendencies, not templates

Describe recurring tendencies qualitatively. Do not turn them into requirements
for matching sentence counts, average sentence length, connector positions, or
paragraph shape.

### Sentence-level tendencies

Inspect only the dimensions relevant to the user's request:

- manageable, compact, or deliberately layered sentences;
- one main scientific move or several linked moves per sentence;
- active or passive voice and where each serves clarity;
- use of condition clauses, qualification, and explicit connectors;
- whether results precede explanation or the reverse;
- how hedge strength and causal verbs track the evidence.

Treat these as options for generation. Do not reproduce a numerical average or
make every sentence follow the same pattern.

### Paragraph-level functions

Identify what each paragraph accomplishes and how it makes the evidence
meaningful. Typical functions include:

- result → quantitative support → independent support → synthesis;
- question → relevant evidence → comparison or test → answer;
- observation → intermediate inference → mechanism → local implication;
- established point → tension or gap → study-specific resolution.

Use the functional sequence that fits the author's material. The author's
evidence may require a different order from the source.

### Reasoning and evidence

Inspect:

- how many inferential steps connect observation to interpretation;
- when independent evidence is combined before a stronger claim;
- how association, correlation, mechanism, and causation are separated;
- how competing interpretations are handled;
- where the source narrows scope or chooses a strong conclusion;
- how figures, tables, numbers, comparisons, and literature enter the chain.

Transfer the reasoning granularity and evidence discipline, not the source's
facts or conclusions. If the author's supplied evidence cannot support an
analogous step, omit it or report the gap.

### Information density and closure

Consider how much information each sentence and paragraph carries, whether the
source repeats an already visible result, and what the final sentence does:
local synthesis, mechanism judgment, broader significance, transition, or
boundary. Use this to decide what the author's paragraph needs. Do not preserve
redundancy or force a source-like paragraph length.

### Scientific tone

Study the relationship between evidence and language strength. Note when the
source uses `show`, `demonstrate`, `indicate`, `suggest`, or `may`, and what
conditions justify those choices. Transfer the calibration principle to the
author's evidence; do not copy the source's favourite verbs mechanically.

## Select features before drafting

After extraction, make a short working selection of the features that serve the
author's section. Apply this priority order:

1. scientific facts, data, conditions, and identifiers;
2. the author's current, author-approved claim and interpretation;
3. the author's own evidence and the most natural inference order;
4. the section's scientific function and intended reader;
5. the author's established voice and terminology;
6. selected transferable features from the reference.

If applying a feature would change the author's structure, emphasis, claim
strength, or voice, report the feature and the trade-off before applying it.

## Generate and review original prose

Write from the author's evidence using the selected features as constraints on
clarity, density, reasoning visibility, and tone. The result may have a
different number of sentences, a different order, and different connective
language from the source.

Before delivery, check:

- every scientific statement comes from the author's supplied material or a
  verified source;
- the source's facts, mechanisms, numbers, conditions, limitations, and novelty
  claims have not entered without authorization;
- the inferential bridge is visible where the author's claim requires it;
- wording, metaphors, and technical phrasing are original or unavoidable field
  terminology;
- the author's existing effective voice has not been replaced by a source
  voice;
- the paragraph does not preserve a recognizable source skeleton merely because
  the selected features were applied.

If the user explicitly wants to see the source structure, route to the
structural-mapping mode in [reference-use.md](reference-use.md). Keep that
diagnostic output separate from the final manuscript-ready text.
