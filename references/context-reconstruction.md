# Reconstructing current project state

Use this protocol before drafting when the available context includes agent
handoffs, project logs, revision histories, old drafts, reviewer notes,
literature notes, task summaries, or records from multiple sessions. These
materials help recover the current project state; their presence does not make
them manuscript evidence or manuscript content.

## Choose the lightest effective mode

For a short, coherent history, reconstruct the current state within the same
editing pass and use it as the immediate basis for drafting.

For a long history, multiple handoffs, repeated corrections, or conflicting
records, use context isolation when an independent agent or fresh context is
available. One state-reconciliation pass reads the raw history and prepares a
clean writer packet. The writing pass receives that packet and the necessary
source material, rather than inheriting the raw history. Do not add an
independent agent to an ordinary edit when the same state can be recovered
reliably in place.

## Reconstruct before writing

Classify each relevant item by its present function:

- **Active author state**: the current interpretation, terminology, claim
  scope, and writing decision confirmed by the author or current project basis.
- **Evidence**: data, figures, tables, source text, and verified literature that
  can support the active state. Preserve a pointer to the actual source.
- **Open decision**: a question whose resolution could change the affected
  mechanism, causal claim, scope, or conclusion.
- **Superseded state**: an earlier interpretation, term, or direction replaced
  by a later author decision. It is useful for preventing regression, not for
  drafting.
- **Process record**: what an agent inspected, attempted, worried about, or
  reported during coordination. It supports task continuity, not scientific
  claims.

Resolve status from the author's explicit decisions and the actual current
manuscript, data, figures, and inspected sources. Do not treat recency, repeated
mention, formal wording, or an agent-generated summary as proof that a statement
is current or scientifically supported. If a material conflict cannot be
resolved from those sources, ask the author and pause only the affected passage.

## Prepare the writer packet

The writer packet is an internal working basis unless the user asks to see it.
Include only what the writing pass needs:

- the current author-approved claim or interpretation;
- the evidence and source pointers supporting it;
- the paragraph or section function;
- the authorized scope, terminology, and requested style;
- an unresolved decision only when it blocks the affected text.

Keep superseded positions, rejected wording, non-blocking open questions,
process notes, audit trails, and agent self-explanations outside the writer
packet. Preserve them in the project history when useful, but do not pass them
forward merely to demonstrate continuity.

## Context-isolated agent handoff

When an independent state-reconciliation agent is warranted, give it access to
the raw project history and primary artifacts. Ask it to produce:

1. a clean writer packet grounded in current author decisions and source
   pointers;
2. a separate report of genuinely unresolved conflicts that require author
   input.

Start the writing agent with a fresh or minimal context and provide only the
writer packet, the necessary evidence, and the user's current request. Do not
forward the conflict report unless the author has resolved it and the decision
belongs in the packet. A subagent that inherits the full conversation does not
provide meaningful context isolation.

If separate context is unavailable, perform the same reconstruction explicitly
before drafting and treat the resulting writer packet as the controlling state.

## Draft and verify

Write from the active state as if it had been the starting point. Apply the
manuscript admission test in
[conversation-to-manuscript.md](conversation-to-manuscript.md) to any contextual
material that still appears useful.

Before delivery, inspect every contrast, caveat, and alternative explanation.
Retain it only when both sides are scientifically live and the comparison serves
the reader. Remove material whose only source is a superseded state, an open
task, or an agent's need to show that it inherited the project history.
