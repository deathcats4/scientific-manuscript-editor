# Using user-supplied references

This protocol applies when the user provides a paper, excerpt, DOI, citation,
or reading note and asks the editor to read, learn from, cite, compare, or
borrow from it.

Reading a source creates material for the collaboration workspace first. Use
the manuscript admission test in
[conversation-to-manuscript.md](conversation-to-manuscript.md) before carrying
source-reading notes, caveats, or comparisons into the paper.

## Identify the source's role before using it

Separate the supplied source's authors, observations, interpretations, and
claims from the manuscript author's current question, evidence, interpretation,
and intended claim. A similar topic or mechanism name does not merge the two
positions.

Classify what the user wants from the source:

- **Facts or background**: definitions, context, established observations, or
  conditions the source genuinely supports.
- **Evidence support**: a source that directly supports a statement already
  present in the manuscript. Check the specific object, conditions, scope, and
  evidence type rather than citing a related topic.
- **Reasoning model**: how the source moves from observation to immediate
  meaning, intermediate inference, mechanism, and implication.
- **Style sample**: transferable tendencies in clarity, information density,
  paragraph progression, scientific tone, or literature placement. Load
  [style-learning.md](style-learning.md) only when this is actually requested.
- **Interpretive aid**: a model or mechanism that helps organize the author's
  observations but is not yet adopted as the manuscript's framework.
- **Competing framework**: a mechanism or theory whose adoption could change
  the manuscript's central interpretation, causal claim, scope, or conclusion.
- **Structural-mapping exercise**: an explicit teaching, diagnostic, or practice
  request to map the author's material onto a source passage's functional
  structure. This is an optional mode, not the default for style requests.

If the user's request is ambiguous, ask which of these roles is intended when
the choice would change the output. Do not perform full style analysis merely
because a paper is being cited or read for background.

## Separate transferable features from source content

When reasoning or style learning is requested, first extract only the features
that can be transferred to the author's task. The source can inform:

- paragraph function and the order in which evidence is made meaningful;
- the granularity of inferential bridges;
- how independent evidence is combined before a stronger interpretation;
- the relationship between evidence strength and claim language;
- information density, sentence manageability, and paragraph closure;
- the role and timing of literature, comparisons, and limitations;
- selected tendencies in voice, directness, and qualification.

These are tendencies, not a sentence template or a target for measurable
similarity. The author's scientific facts, evidence, current interpretation,
section function, and author-approved scope remain the controlling material.
If applying a source feature would change the manuscript's organization,
emphasis, mechanism, claim strength, or author voice, report the choice and its
consequence before changing the affected text.

## Style- and reasoning-conditioned rewriting

For an ordinary request to learn from a paper, use this order:

1. Establish the author's current claim, evidence, inference chain, section
   function, and author voice.
2. Extract the source's transferable reasoning or style features only for the
   requested purpose.
3. Select the features that serve the author's target section and reader. Do
   not average incompatible papers into a generic voice or apply every feature
   found in the source.
4. Reorganize the author's own material according to the selected features.
   Preserve the author's evidence order when it is scientifically more natural
   than the source's order.
5. Check that the result does not import source-specific facts, mechanisms,
   conclusions, limitations, numbers, experimental conditions, novelty claims,
   distinctive wording, or a recognizable sentence skeleton.

Ordinary style learning does not require matching sentence count, sentence
order, connector placement, paragraph length, long–short sentence pattern,
cadence, or the location of the source's conclusion. Use the source to improve
the way the author's argument is expressed, not to make the author's paragraph
look like the source paragraph.

## Explicit structural-mapping mode

Enter this mode only when the user explicitly asks for sentence-by-sentence
analysis, a paragraph skeleton, a structure-mapped exercise, a side-by-side
logic comparison, or equivalent wording that makes the mapping itself the
deliverable.

In this mode, a sentence-and-clause map may record:

1. the source passage's sentence and clause functions;
2. where observations, interpretation, literature, mechanism, and implication
   enter;
3. the role of connectors, qualifications, citations, and the main claim;
4. the granularity and information-density changes across the paragraph.

Use the map for teaching, diagnosis, or practice. Do not copy distinctive
phrasing, metaphors, or technical expressions merely because they occupy the
same slot. A mapping exercise is not automatically a manuscript-ready draft.
If the user wants final manuscript prose after the exercise, perform a second
pass that keeps the approved reasoning features but generates original wording
and an author-appropriate structure.

## Author voice and source boundaries

Treat the reference as one possible source of useful features, not as a voice
that should replace the author's own. If the author's existing prose is clear,
stable, and professional, preserve those strengths and absorb only the source
features that solve the requested problem. A more complex source does not
justify making every author sentence more complex.

Do not transfer automatically:

- source-specific scientific facts, mechanisms, conclusions, limitations,
  numbers, conditions, or novelty claims;
- a source's interpretation merely because the same topic appears;
- a citation or reference placement whose claim fit has not been checked;
- distinctive wording or a recognizable rhetorical fingerprint.

Facts, evidence, mechanisms, and borrowed conceptual frameworks require the
appropriate source attribution and evidence check. A source's exposition can be
used as a reasoning model without adopting the source's scientific position.

## Several reference papers

Recognizable style learning does not come from averaging several papers. Assign
each paper the role it can genuinely serve, for example:

- one source for Results compression;
- one for Discussion mechanism reasoning;
- one for Introduction gap framing.

Use different sources by section when that helps. If their style or scientific
frameworks conflict, let the author's goal, section function, evidence, and
reader determine the result. Choosing between competing mechanisms or theories
remains an author decision under the
[author decision rule](evidence-and-citations.md#author-decision-rule-for-competing-mechanisms).

## Completion rule

If the source is used only for facts, background, or citation support, complete
that task without unnecessary style analysis. If reasoning or style learning is
requested, state or report the selected transferable features when they affect
the draft, then apply them within the author's scientific and stylistic
boundaries. If structural mapping is requested, keep the mapping distinct from
the final manuscript-ready prose. In every mode, preserve the author's current
explanation and surface any unresolved scientific or author-voice choice before
changing it.
