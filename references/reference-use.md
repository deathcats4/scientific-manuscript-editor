# Using user-supplied references

This protocol applies when the user provides a paper, excerpt, DOI, citation,
or reading note and asks the editor to read, learn from, cite, compare, or
borrow from it.

Reading a source creates material for the collaboration workspace first. Use
the manuscript admission test in
[conversation-to-manuscript.md](conversation-to-manuscript.md) before carrying
source-reading notes, caveats, or comparisons into the paper.

## Separate the two authors' positions

First record, from the supplied source, what the cited authors actually studied,
observed, interpreted, and claimed, including the conditions and scope. Keep
that separate from the manuscript author's current question, observations,
interpretation, and intended claim. A similar topic or a different mechanism
name does not merge the two positions.

## Classify the requested borrowing

Identify the intended object before using the source:

- **Facts or background**: definitions, context, established observations, or
  conditions that the source genuinely supports.
- **Terminology or expression**: a term, translation, sentence pattern, or
  paragraph organization. For ordinary borrowing, retain the function and use
  the manuscript author's content. When the author asks to imitate, follow, or
  write like a supplied passage, use the close structural mapping below.
- **Argumentation pattern or inference exposition**: how the source moves from
  observation to immediate meaning, intermediate inference, mechanism, and
  implication; how it combines evidence and makes the reasoning visible. Use
  this as a model for reasoning granularity and paragraph progression, not as a
  source of facts or conclusions.
- **Evidence support**: a source that directly supports a statement already
  present in the manuscript. Check that the source supports the specific claim,
  not merely a related topic.
- **Interpretive aid**: a useful model or mechanism that helps organize the
  author's observations but is not being adopted as the manuscript's framework.
- **Competing framework**: a mechanism or theory whose adoption could change
  the manuscript's central interpretation, causal claim, scope, or conclusion.

Facts, terminology, structure, expression, and directly relevant support can be
integrated and delivered when they do not change the author's framework. An
interpretive aid should be used only within the conditions and evidence that the
source supports; keep the author's current explanation visible.

## Close structural imitation

When the author asks to imitate, follow, learn the prose of, or write according
to a supplied passage, default to close structural imitation unless the author
asks only for its general logic. The first draft should visibly retain the
source passage's rhetorical architecture while carrying only the manuscript
author's scientific content.

Build a sentence-and-clause map before drafting. Record:

1. the number and order of sentences;
2. the scientific function of each sentence and major clause;
3. where observations, interpretation, literature, mechanism, and implication
   enter;
4. the location and function of connectors, qualifications, citations, and the
   main claim;
5. relative sentence length, information density, repetition, and paragraph
   cadence.

Map each source slot to the author's supplied evidence or interpretation. Then
write the first pass in the same functional order and approximately the same
granularity and rhythm. Keep the source's placement of the reasoning bridge and
the timing of its conclusion when the author's evidence supports those moves.
Replace every source-specific object, result, mechanism, and conclusion with the
author's material. A slot with no supported counterpart is adapted or omitted;
it is never filled with a fact from the source.

The first pass is a structural shadow, not an independent rewrite. Do not
reorder it, compress it, modernize it, or convert it into the editor's usual
house style merely because another formulation seems more elegant. After the
mapping is stable, make only the changes needed for grammaticality, scientific
accuracy, continuity with the surrounding manuscript, and non-duplication of
distinctive wording. Common disciplinary syntax and unavoidable technical
phrasing may remain; distinctive expressions must be recast.

When the author emphasizes wanting to see the resemblance or is testing the
imitation, deliver this close structural draft first. Preserve it as the basis
for the next revision rather than silently replacing it with a more polished
but less recognizable version. If the author asks only for manuscript-ready
text, use the same two-pass process internally and return the final text.

## Several reference papers

Recognizable imitation requires a dominant local model. If the author names a
lead paper, use it as the primary model. Otherwise choose, for each target
paragraph, the source passage whose scientific function most closely matches
that paragraph. Use other papers only for isolated compatible moves the lead
passage lacks; do not average several prose styles into a generic voice.

Keep source-specific claims and mechanisms separate. A source's reasoning move
can be mapped only when the author's own evidence supports the corresponding
step. If several sources offer incompatible scientific frameworks and choosing
one would change the author's interpretation, use the author decision gate. A
request to imitate their exposition alone does not trigger that gate.

## Default treatment of different mechanisms

A paper proposing a different mechanism is normally background, a parallel
explanation, or a study of another system. Do not turn it into a rebuttal or a
mechanism survey merely because it was read. The manuscript may state the
explanation supported by its own evidence without proving that no other
mechanism exists.

## Author decision gate

Pause the affected interpretation and ask the author before writing a comparison
or changing the framework only if all three conditions appear to hold:

1. The source addresses the same core phenomenon under genuinely comparable
   objects and conditions.
2. Its mechanism can plausibly account for the supplied observations.
3. Choosing between the mechanisms would change the manuscript's central
   interpretation, causal relationship, scope, or conclusion.

When pausing, give the author four concrete items:

- what the source claims;
- what the manuscript currently claims;
- why the two may be in real tension;
- which sentence, mechanism, or scope decision would be affected.

Ask whether the author wants the source treated as background, a parallel
interpretation, or a substantive comparison. Until the author answers, do not
add a rebuttal, select a mechanism, weaken the current explanation, or expand
the discussion. Continue unrelated language edits that do not depend on this
choice.

## Completion rule

If the gate is not triggered, integrate only the requested and source-supported
material, preserve the author's current explanation, and deliver the requested
revision. Do not report a conflict merely because the source contains a
different viewpoint.
