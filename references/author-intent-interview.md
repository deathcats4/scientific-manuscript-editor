# Author-intent interview

Use this reference after recovering the supplied basis when a manuscript
request still has an unresolved choice that would change the requested content.
The goal is shared understanding of the work to perform, not permission for
ordinary editorial choices or a full adversarial Grill.

## Decision tree

Work through the frontier of currently answerable decisions. The usual nodes
are:

1. **Operation** — local edit, translation, logic/evidence review, drafting,
   restructuring, citation review, naturalness review, or manuscript-wide
   synthesis.
2. **Scope** — sentence, paragraph, section, selected sections, or full
   manuscript; identify the intended reader endpoint when section scale is
   involved.
3. **Author state** — the current manuscript's working position and any explicit
   accepted, rejected, or provisional claims, mechanisms, causal relations,
   contribution framing, terminology, and conclusion strength. Keep their
   origins recoverable under [manuscript-context.md](manuscript-context.md).
4. **Evidence basis** — which observations, figures, tables, methods,
   limitations, and inspected sources support the requested move; mark any
   load-bearing gap.
5. **Source role and authorization** — whether a supplied paper is being used
   for facts, citation support, terminology, reasoning, comparison, or style;
   ask about its role only when unrecoverable and consequential. Request new
   literature retrieval only when needed and not already authorized.
6. **Delivery** — manuscript-only text, findings before rewriting, a proposed
   organization, a provisional draft, or progressive paragraph-by-paragraph
   collaboration.

Do not ask every node by default. Start with the earliest unresolved node whose
answer changes the downstream route. If several frontier questions are
independent, ask them in one round. If a later question depends on an earlier
answer, defer it to the next round. If recovery resolves the operation, author
position, evidence basis, and delivery, proceed without an interview even for a
substantive mechanism passage.

## Round format

Use a compact format for an actual unresolved choice, with a recommendation
when the supplied basis supports one. Route recommendations are proposals,
not author commitments. For an operation that remains genuinely ambiguous
after recovery, a round can be:

```text
❓ Q1 — 处理目标：你希望我只改语言，还是同时检查这段解释是否被结果支持？

➡️ 建议：先做科学逻辑与证据边界审查，因为当前请求涉及机制解释。
```

After the author answers, update the working state and ask only the new
frontier. Do not repeat settled decisions or turn the interview into a list of
questions whose answers are already present in the manuscript.

When a question would choose a mechanism, causal relation, or conclusion
strength, present the supported options and their consequences. Keep a newly
recommended scientific position provisional until the author accepts it;
evidence determines whether it is defensible, and acceptance does not verify
the evidence. Do not downgrade an existing supported working position merely
because no separate acceptance record was recovered.

## Facts versus decisions

Facts are the agent's job. Read the supplied text, figures, tables, methods,
notes, and accessible source material before asking the author to restate them.
The author's decisions are the author's job. Ask when an unresolved choice
would change the mechanism, comparison, claim strength, or source role of the
requested result. The current manuscript supplies the working position for
ordinary editing; a missing explicit acceptance record alone is not a question.

If a load-bearing fact or source is missing, report the concrete gap and why it
changes the requested result. Do not use a plausible default to close it. The
author may supply the material, authorize retrieval or analysis, or accept a
visibly provisional draft with the gap marked.

## Route discovery and Grill boundary

If the user does not know what to ask, return up to three relevant task modes,
what each mode would deliver, and one copyable next request. This route note is
an orientation aid; it does not start a full Grill or authorize retrieval.

A full Grill is a separate, user-requested pressure test. Start it only when
the author explicitly asks to be grilled, challenged, or stress-tested. The
ordinary interview resolves the smallest open choice needed to execute the
manuscript task.

## Completion

The interview is complete when the operation, scope, relevant author state,
evidence basis, source authorization, and delivery form are either settled or
explicitly marked as open constraints. Return to the main skill, apply the
selected depth and references, and keep unresolved scientific choices outside
the manuscript until the author accepts them.

## Example: Discussion mechanism

User: “帮我把这段 Discussion 写得更有说服力。”

First recover the passage, supporting results, relevant manuscript context,
and current author position. If the mechanism and its strength are already
settled and supported, improve the evidence-to-inference reasoning and language
directly. The request does not require an operation questionnaire or a weaker
claim by default.

If two defensible interpretations remain and the supplied material does not
settle which one belongs in the manuscript, ask that one consequential choice:

```text
❓ 当前解释：稿件保留解释 A，笔记又提出解释 B，现有材料不能确定你要采用哪一个。
你希望保留 A 并完善其论证，还是先比较 A、B 再确定正文立场？

➡️ 建议和后果：按已读证据说明哪条路线更有依据，以及各自会怎样改变这段论证；
尚未被你接受的新判断先作为建议，不写成正文的既定立场。
```

Ask a later question only if the answer opens a new consequential choice; do
not automatically add comparison or retrieval rounds. If the supplied results
omit a boundary condition on which the explanation depends, report that
material-sufficiency gap and the available resolutions instead of drafting the
condition from memory.
