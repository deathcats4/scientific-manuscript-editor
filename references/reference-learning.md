# Reference learning

Use this reference when the author supplies a paper, excerpt, DOI, citation, or
reading note and wants it read, cited, compared, or learned from.

## Identify the requested role

A reference may serve as:

- verified factual or background support;
- support for a manuscript statement;
- terminology or a conceptual definition;
- a reasoning model showing how evidence becomes an interpretation;
- a style sample for information density, rhythm, directness, qualification, or
  paragraph movement;
- an interpretive aid or competing framework;
- an explicit teaching example for structural mapping.

Do not perform every form of analysis merely because a paper is present. If the
role would materially change the output and cannot be inferred, ask a focused
question; otherwise use the narrowest role consistent with the request.

## Keep source and author science separate

The reference's observations, mechanisms, limitations, and conclusions remain
the reference authors' content. The manuscript author's facts, evidence,
interpretation, scope, and terminology remain controlling.

Transfer only what the requested role permits. A style or reasoning model may
inform:

- how quickly a paragraph reaches its scientific point;
- how much inference is made explicit;
- how evidence types are combined;
- when literature enters;
- how claim strength matches support;
- how a paragraph closes or moves to the next question.

Do not automatically transfer source-specific facts, mechanisms, conditions,
limitations, novelty claims, distinctive wording, sentence count, connector
placement, cadence, or a recognizable structural skeleton.

## Use the source faithfully

For factual or citation use, inspect enough of the source to verify the exact
claim and its scope. For reasoning or style learning, first identify the
transferable tendency, then rebuild the author's own material around its own
scientific relationships. If the author's existing organization is more
scientifically natural, preserve it.

Several references need not be averaged into one generic voice. Give each only
the function it genuinely serves—for example, one for Results compression and
another for Discussion reasoning.

## Structural mapping is exceptional

Map sentence or clause functions only when the author explicitly asks for a
side-by-side analysis, teaching exercise, or structure-mapped draft. Keep that
map separate from manuscript-ready prose. A final draft should retain useful
reasoning features while using original language and an author-appropriate
organization.

## Scientific choices remain visible

A reference can suggest a mechanism or framework without authorizing its
adoption. If using it would change the manuscript's mechanism, causal claim,
evidence role, scope, or conclusion, present the option and its consequences
before treating it as the paper's position.
